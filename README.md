# ВагонДок

Клиентское приложение для учёта железнодорожных вагонов и документов: ГУ-2Б, ГУ-2В, ГУ-45, ГУ-46 и железнодорожных накладных. Проект рассчитан на публикацию как статический сайт, в том числе через GitHub Pages.

## Возможности

- извлечение реального текстового слоя PDF с помощью PDF.js;
- локальное OCR сканов через Tesseract.js после явного согласия пользователя;
- извлечение типа документа, всех 8-значных номеров вагонов, номера накладной, дат и станций;
- проверка контрольной цифры номера грузового вагона;
- обязательный экран ручной проверки перед сохранением;
- одна карточка на номер вагона, к которой прикрепляются все связанные документы;
- хранение исходных PDF и метаданных в IndexedDB;
- фильтры по году, месяцу, вагону, типу и комплектности;
- защита от повторной загрузки идентичного файла по SHA-256;
- экспорт отфильтрованного реестра в JSON.

Приложение не создаёт номера, даты, станции или другие реквизиты. Нераспознанные значения остаются пустыми и показываются как «Не распознано».

## Локальный запуск

ES-модули требуют запуск через HTTP-сервер:
Прототип интерфейса для автоматизированного учёта железнодорожных документов. Приложение принимает PDF-файлы, определяет тип формы и номер вагона из имени файла, группирует документы по вагонам и формирует скачиваемый реестр комплектности.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для первоначальной загрузки PDF.js и OCR требуется доступ к CDN. Содержимое PDF обрабатывается в браузере и не отправляется в облачный OCR.

## Хранение и ограничения

Документы сохраняются только в IndexedDB текущего браузера. Они не синхронизируются между устройствами и будут удалены при очистке данных сайта. Для совместной работы, резервного копирования, разграничения доступа и долговременного хранения потребуется серверная часть.

Извлечение реквизитов основано на шаблонах текста и всегда требует подтверждения. Качество OCR зависит от качества скана. Импорт Excel/Word предусмотрен как следующий отдельный модуль: модель данных уже отделяет документы от агрегированных карточек вагонов.
