# ВагонДок

Прототип интерфейса для автоматизированного учёта железнодорожных документов. Приложение принимает PDF-файлы, определяет тип формы и номер вагона из имени файла, группирует документы по вагонам и формирует скачиваемый реестр комплектности.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для демонстрации распознавания используйте имена файлов вида `ГУ-45_55674218.pdf`.
